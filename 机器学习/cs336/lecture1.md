# Lecture 1：课程概览与分词

> **记忆口诀：底层要懂，规模要验；字节保底，高频合并；先分块，再合并。**

1. **课程学什么？** 从头构建模型：基础组件 → 系统加速 → 扩展定律 → 数据工程 → 后训练。核心问题：**预算有限，怎样训练出更好的模型？**

2. **语言模型干什么？** 根据前面的 token，预测下一个 token 的概率。分词器负责 **文本 ↔ token ID**；token 不一定是完整单词。字节级 BPE 应能原样还原：`decode(encode(text)) = text`。

3. **BPE 怎么记？** 从 **256 种字节**出发，反复合并最频繁的相邻 token 对，例如 `t + h → th`，再 `th + e → the`。**训练时统计频率、学规则；编码新文本时按学好的合并顺序执行，不重新学规则。**

4. **为什么不无限扩大词表？** 词表大，通常能把文本切得更短；但嵌入层和输出层更大，罕见 token 也难学好。压缩比 = **原文 bytes ÷ token 数**；数值越大，同一文本的 token 越少。

5. **分词怎样避免慢？** 正则先分块，BPE 只在块内合并，可并行处理。不要每条合并规则都重新扫描整篇文章。`V` 是词表，`|V|` 是 token 数；不计特殊 token，合并规则数为 `|V| − 256`。

6. **小模型能教会什么？** 学机制、学测量与性能分析的方法；**小模型上的最佳配置，不保证适用于大模型**。规模扩大后，瓶颈和能力表现可能变化，结论要验证。

7. **不用分词器，还要解决什么？** 小碎片要组合成更有用的表示；不同内容应合理分配计算。这是本讲提出的设计方向。“局部信噪比低”在这里指：**单个字节往往不足以看出整体意思**。
