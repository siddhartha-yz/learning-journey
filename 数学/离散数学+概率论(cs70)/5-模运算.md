# CS70 第 8 节：模运算 II —— 大白话版

这一节真正想解决的问题只有一条主线：

\[ \boxed{ \text{模运算里怎么做“除法”？} } \]

最后答案是：

\[ \boxed{ \text{除以 }a \quad\Longleftrightarrow\quad \text{乘以 }a\text{ 的模逆元} } \]

而要判断逆元存不存在、怎么找到逆元，就会自然引出：

\[ \boxed{\gcd\rightarrow\text{欧几里得算法}\rightarrow\text{扩展欧几里得算法}} \]

------

## 1. 先回顾：什么叫 mod？

最直观就是钟表。

24 小时制里：

```
... 22 → 23 → 0 → 1 → 2 ...
```

比如现在 9 点，19 小时以后：

\[ 9+19=28 \]

但钟表绕了一圈：

\[ 28\bmod 24=4 \]

所以是 4 点。

本质上：

\[ a\bmod n \]

就是：

> \(a\) 除以 \(n\) 以后留下的余数。

写成除法算法就是：

\[ a=qn+r,\qquad 0\le r<n \]

那么：

\[ a\bmod n=r. \]

比如：

\[ 17=2\times7+3 \]

所以：

\[ 17\bmod7=3. \]

甚至负数也一样。

例如：

\[ -2\bmod7=5 \]

因为：

\[ -2=(-1)\times7+5. \]

课堂就是先从钟表直觉正式化这个概念。   粘贴的文本 (1)

------

# 2. `mod` 和“同余”不是一个东西

这是这一节很容易混的地方。

### `a mod n`

这是一个函数：

\[ a\bmod n=r. \]

输入一个整数 \(a\)，输出余数 \(r\)。

例如：

\[ 17\bmod7=3. \]

------

### \(a\equiv b\pmod n\)

这个不是在“算一个数”。

它是在说：

> \(a\) 和 \(b\) 除以 \(n\) 后，余数一样。

例如：

\[ 17\equiv3\pmod7 \]

因为它们模 7 都余 3。

还可以有：

\[ 3\equiv10\equiv17\equiv24\pmod7. \]

直观上，就是把所有整数按照“余数”分成几堆：

```
余 0：..., -14, -7, 0, 7, 14, 21, ...
余 1：..., -13, -6, 1, 8, 15, 22, ...
余 2：..., -12, -5, 2, 9, 16, 23, ...
...
```

模 7 的世界实际上只关心这 7 类。

------

## 3. 同余最有用的判定

\[ \boxed{ a\equiv b\pmod n \iff n\mid(a-b) } \]

为什么？

如果两者余数一样：

\[ a=q_1n+r \]\[ b=q_2n+r \]

相减：

\[ a-b=(q_1-q_2)n. \]

所以 \(a-b\) 一定是 \(n\) 的倍数。

反过来也成立。

所以以后看到：

\[ a\equiv b\pmod n \]

脑子里可以直接翻译成：

\[ \boxed{a-b\text{ 是 }n\text{ 的倍数}} \]

这是后面证明最好用的形式。  

------

# 4. 为什么模运算里可以随便“先取余”？

比如：

\[ 1000002+1000004\pmod7 \]

没必要先算巨大数字。

因为：

\[ 1000002\equiv ? \]

先把每个数模 7 简化，再加就行。

背后的定理是：

如果

\[ a\equiv b\pmod n \]

以及

\[ c\equiv d\pmod n, \]

那么：

\[ a+c\equiv b+d\pmod n \]

以及

\[ ac\equiv bd\pmod n. \]

也就是说：

> 在加法、减法、乘法里，你可以随时把一个数换成与它同余的更小数字。

例如：

\[ 100\equiv2\pmod7 \]

所以以后表达式里看到 100，可以直接当成 2 用。

这就是模运算真正方便的地方。

------

# 5. 加减乘都很自然，真正麻烦的是除法

普通数学里：

\[ 3x=2 \]

我们直接：

\[ x=\frac23. \]

但模运算只在整数余数类里面玩。

例如模 5：

\[ 3x\equiv2\pmod5. \]

你不能简单地写：

\[ x\equiv\frac23. \]

因为模 5 的世界里我们要的是：

\[ 0,1,2,3,4 \]

这些余数类。

那“除以 3”到底是什么意思？

------

# 6. 模逆元：模运算里的“除法”

普通数学里：

\[ \frac13\times3=1. \]

所以所谓“除以 3”，本质就是：

> 找一个东西，乘上 3 可以把 3 消掉。

模 5 中：

\[ 3\times2=6\equiv1\pmod5. \]

于是：

\[ \boxed{2\text{ 就是 }3\text{ 在模 }5\text{ 下的逆元}} \]

记作：

\[ 3^{-1}\equiv2\pmod5. \]

所以：

\[ \boxed{\text{模 }5\text{ 下除以 }3 = \text{乘以 }2} \]

这和普通除法的思想完全一样。

------

## 7. 用逆元解方程

例如：

\[ 3x\equiv2\pmod5. \]

我们知道：

\[ 3^{-1}\equiv2\pmod5. \]

两边乘 2：

\[ 2\cdot3x\equiv2\cdot2\pmod5. \]

左边：

\[ 2\cdot3\equiv1. \]

所以：

\[ x\equiv4\pmod5. \]

检查：

\[ 3\times4=12\equiv2\pmod5. \]

正确。

因此以后看到：

\[ ax\equiv b\pmod n \]

如果 \(a\) 有逆元 \(a^{-1}\)，就可以：

\[ \boxed{x\equiv a^{-1}b\pmod n} \]

这就是模意义下的除法。课堂用 \(3x\equiv2\pmod5\) 正是在建立这个直觉。 

------

# 8. 但不是所有数都能除

例如模 12 下想除以 3。

也就是说我们需要找到 \(x\)：

\[ 3x\equiv1\pmod{12}. \]

试试看：

```
3×0 ≡ 0
3×1 ≡ 3
3×2 ≡ 6
3×3 ≡ 9
3×4 ≡ 0
3×5 ≡ 3
...
```

永远只有：

\[ 0,3,6,9. \]

根本到不了 1。

为什么？

因为：

\[ 3x-12k \]

永远是 3 的倍数。

不可能等于 1。

真正的问题在于：

\[ \gcd(3,12)=3\neq1. \]

3 和 12 有公共因子，把整个系统“卡住”了。

于是得到本节最重要的定理：

\[ \boxed{ a\text{ 在模 }n\text{ 下有逆元} \iff \gcd(a,n)=1 } \]

也就是：

\[ \boxed{\text{只有 }a\text{ 和 }n\text{ 互质时，才能除以 }a} \]

例如：

\[ \gcd(3,5)=1 \]

所以模 5 下可以除以 3。

但：

\[ \gcd(3,12)=3 \]

所以模 12 下不能除以 3。   

------

# 9. 那怎么快速求 gcd？——欧几里得算法

现在问题又变成：

> 怎么快速算 \(\gcd(a,b)\)？

核心定理：

假设：

\[ a=qb+r. \]

那么：

\[ \boxed{ \gcd(a,b)=\gcd(b,r) } \]

而：

\[ r=a\bmod b. \]

所以：

\[ \boxed{ \gcd(a,b) = \gcd(b,a\bmod b) } \]

这就是欧几里得算法。

------

## 10. 为什么 gcd 不会变？

比如：

\[ 26=2\times10+6. \]

于是：

\[ \gcd(26,10)=\gcd(10,6). \]

为什么？

如果一个数同时整除 26 和 10，那它当然也整除：

\[ 26-2\times10=6. \]

所以：

> 能同时整除 26、10 的数，和能同时整除 10、6 的数，本质是同一批。

因此最大那个公因数当然一样。

就这么简单。

------

# 11. 欧几里得算法实例

计算：

\[ \gcd(26,10). \]

不断“除，然后拿余数继续”：

\[ 26=2\times10+6 \]

所以：

\[ \gcd(26,10)=\gcd(10,6). \]

然后：

\[ 10=1\times6+4 \]

所以：

\[ =\gcd(6,4). \]

继续：

\[ 6=1\times4+2 \]

所以：

\[ =\gcd(4,2). \]

最后：

\[ 4=2\times2+0. \]

余数到 0 了，结束。

最后一个非零余数就是：

\[ \boxed{2}. \]

所以：

\[ \gcd(26,10)=2. \]

整个过程：

```
26,10
  ↓ 26 mod 10 = 6
10,6
  ↓ 10 mod 6 = 4
6,4
  ↓ 6 mod 4 = 2
4,2
  ↓ 4 mod 2 = 0
2,0

答案 = 2
```

课堂还用“用最大的正方形地砖铺满长方形”来解释 gcd，之后才写成递归算法。   

------

# 12. 为什么这里又出现强归纳？

欧几里得算法是递归：

\[ \gcd(a,b) \rightarrow \gcd(b,a\bmod b). \]

注意：

\[ a\bmod b<b. \]

但它不一定是：

\[ b-1. \]

可能一下从 100 跳到 7。

所以和前面讲递归算法一样：

> 递归调用的是“某个更小的问题”，而不是恰好小 1。

因此最自然用强归纳证明正确性。

真正需要证明的核心不是归纳本身，而是：

\[ \boxed{\gcd(a,b)=\gcd(b,a\bmod b)} \]

一旦这个性质证明了，递归正确性几乎就是机械的。   

------

# 13. 但我们最终不是只想求 gcd

别忘了最开始的问题：

\[ \boxed{\text{我想求模逆元}} \]

假设：

\[ \gcd(a,n)=1. \]

我们需要找到：

\[ ax\equiv1\pmod n. \]

这句话等价于：

\[ ax-1 \]

是 \(n\) 的倍数。

也就是存在某个 \(y\)：

\[ ax+ny=1. \]

所以问题突然变成：

\[ \boxed{\text{能不能找到 }x,y\text{ 使 }ax+ny=1？} \]

------

# 14. 扩展欧几里得算法

普通欧几里得算法只告诉你：

\[ \gcd(a,b)=d. \]

扩展欧几里得算法更强，它还能找到：

\[ \boxed{ax+by=d} \]

里的 \(x,y\)。

这叫 Bézout 等式。

例如刚才：

\[ \gcd(26,10)=2. \]

扩展欧几里得会告诉你：

\[ 2=2\times26-5\times10. \]

也就是说：

\[ x=2,\qquad y=-5. \]

------

# 15. \(x,y\) 是怎么来的？——把欧几里得算法倒着走

前面有：

\[ 26=2\times10+6 \]

\[ 10=1\times6+4 \]

\[ 6=1\times4+2. \]

从最后一个开始：

\[ 2=6-4. \]

而：

\[ 4=10-6. \]

代进去：

\[ 2=6-(10-6) \]

\[ =2\times6-10. \]

又有：

\[ 6=26-2\times10. \]

继续代：

\[ 2 = 2(26-2\times10)-10 \]

所以：

\[ \boxed{ 2=2\times26-5\times10 } \]

就这么来的。

扩展欧几里得并不是什么新魔法：

\[ \boxed{ \text{普通欧几里得往下算余数} \rightarrow \text{扩展欧几里得再倒着代回去} } \]

课堂的 26 和 10 的例子就是完整演示这个过程。   

------

# 16. 终于回到模逆元

假设：

\[ \gcd(a,n)=1. \]

扩展欧几里得算法能找到：

\[ ax+ny=1. \]

两边模 \(n\)。

因为：

\[ ny\equiv0\pmod n \]

所以：

\[ ax\equiv1\pmod n. \]

因此：

\[ \boxed{x=a^{-1}\pmod n} \]

这一下全部串起来了。

------

## 17. 例子：求 \(3^{-1}\pmod{10}\)

因为：

\[ \gcd(3,10)=1, \]

所以逆元存在。

扩展欧几里得找到：

\[ 1=7\times3-2\times10. \]

模 10：

\[ 7\times3\equiv1\pmod{10}. \]

因此：

\[ \boxed{3^{-1}\equiv7\pmod{10}} \]

所以：

> 模 10 下“除以 3”，就是“乘以 7”。

例如：

\[ 3x\equiv2\pmod{10} \]

两边乘 7：

\[ x\equiv14\equiv4\pmod{10}. \]

课堂最后又用 \(3\) 和 \(10\) 重新解释了一次这条链条。  

------

# 18. 整节课真正的逻辑链

把所有细节扔掉，只看骨架：

```
普通模运算
   ↓
加减乘都可以正常做
   ↓
但是“除法”怎么办？
   ↓
除以 a = 乘以 a 的逆元
   ↓
逆元要求 ax ≡ 1 (mod n)
   ↓
也就是 ax + ny = 1
   ↓
什么时候能做到？
   ↓
gcd(a,n) = 1
   ↓
怎么判断 gcd？
   ↓
欧几里得算法
   ↓
怎么找到 x？
   ↓
扩展欧几里得算法
```

所以一行记忆：

\[ \boxed{ \gcd(a,n)=1 \Longrightarrow ax+ny=1 \Longrightarrow ax\equiv1\pmod n \Longrightarrow x=a^{-1} } \]

这就是第 8 节最核心的东西。

------

# 19. 这节最该记住的 6 个式子

\[ \boxed{ a\equiv b\pmod n \iff n\mid(a-b) } \]

\[ \boxed{ a+c\equiv b+d,\qquad ac\equiv bd } \]

\[ \boxed{ aa^{-1}\equiv1\pmod n } \]

\[ \boxed{ a^{-1}\text{ 存在} \iff \gcd(a,n)=1 } \]

\[ \boxed{ \gcd(a,b)=\gcd(b,a\bmod b) } \]

\[ \boxed{ \gcd(a,b)=ax+by } \]

其中最后一个不是说任意 \(x,y\) 都行，而是扩展欧几里得能够找到合适的 \(x,y\)。

如果只看一遍第 8 节，我认为应优先把“**为什么模除法 = 乘逆元，以及为什么互质决定逆元存在**”这两个直觉彻底搞懂；欧几里得算法本身只是后面负责把这个逆元算出来的工具。
