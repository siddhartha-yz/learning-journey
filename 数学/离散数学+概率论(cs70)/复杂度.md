时间复杂度描述的是：

> 当输入规模变大时，算法运行所需的“基本操作次数”增长得有多快。

它通常不关心具体运行了几秒，而关心增长趋势。

例如一个算法处理 N 个元素时，大约执行 N 次操作，那么时间复杂度就是

\[ O(N) \]

如果大约要执行

\[ N^2 \]

次操作，那么就是

\[ O(N^2) \]

如果无论 N 多大，都只执行固定次数操作，那么就是

\[ O(1) \]

所以时间复杂度本质上是在回答：

> **输入规模扩大后，计算量会以什么速度增长？**

例如遍历一棵有 N 个节点的树，每个节点访问一次，所以通常是

\[ O(N) \]



O() 叫做“大 O 记号”，它本身只是描述“增长速度上界”的数学记号。

例如：

\[ O(N) \]

表示增长速度至多和 N 同阶。

它经常用来表示时间复杂度，所以大家常说“时间复杂度是 O(N)”。

但 O() 也可以表示别的复杂度，比如：

- 时间复杂度
- 空间复杂度

所以更准确地说：

> O() 不是时间复杂度本身，而是描述复杂度增长速度的一种记号。
