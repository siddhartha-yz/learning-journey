# 看起来没有利用命题中的关键结构也是归纳错误的一个警报。

对，这个判断很重要。

如果你在做归纳证明时发现：

> 证明过程几乎没用到命题里最关键的特殊结构，

那就应该立刻警觉：

\[ \boxed{\text{这个证明可能证明得“太强了”，强到其实是假的}} \]

这里超立方体的关键结构明明是：

\[ Q_{n+1}=\text{两个 }Q_n+\text{对应顶点之间的横向边} \]

尤其那些“横向边”正是超立方体区别于“两坨互不相干的 \(Q_n\)”的核心。

但那个错误证明只是：

\[ S=S_0\cup S_1 \]

然后分别对左右两半套归纳假设，再相加，几乎完全没有利用：

\[ 0x\leftrightarrow1x \]

这些横向边。

那就很可疑：

> 如果把所有横向边都删掉，这个证明好像照样成立。

可横向边全删以后，整个图都可能不连通了，“没有大瓶颈”显然不可能还成立。

所以这是一个很强的检查方法：

\[ \boxed{ \text{如果证明删掉关键结构后仍然原封不动成立，往往说明证明有问题。} } \]

课堂老师其实就是在强调这个：那个错误归纳甚至没有真正使用超立方体的边结构，所以证明从根上就值得怀疑。   

这个思维可以推广到很多证明：如果命题明明依赖“连通”“单调”“凸性”“独立性”“特殊递归结构”等条件，但你的证明一个都没用，优先检查是不是哪里偷换了前提。
