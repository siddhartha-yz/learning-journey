DFS 和 BFS 都是“遍历图”的方法，也就是从一个点出发，把能到达的节点都访问一遍。

DFS（Depth-First Search，深度优先搜索）：

> 一条路先走到底，走不动了再回头。

例如：

```
    1
   / \
  2   3
 / \
4   5
```

一种 DFS 顺序可能是：

```
1 → 2 → 4 → 5 → 3
```

直觉上很像“走迷宫”：先沿一条路不断深入。

BFS（Breadth-First Search，广度优先搜索）：

> 先访问离起点最近的一圈，再访问下一圈。

同一棵树，一种 BFS 顺序是：

```
1 → 2 → 3 → 4 → 5
```

可以理解成水波从起点一层层向外扩散。

最简单的区别：

- DFS：**先往深处走**
- BFS：**先往周围铺开**

实现上通常：

- DFS 用递归或栈
- BFS 用队列

在树或图里，这两个都是最基础的搜索算法。
