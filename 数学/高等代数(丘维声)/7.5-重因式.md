## 7.5 重因式｜做题必备总结

以下结论均在教材的**数域 \(K\)** 上成立。

### 一、必须牢记的5个结论

**① 重因式的定义**

设 \(p(x)\) 不可约，若

\[ p^k\mid f,\qquad p^{k+1}\nmid f \]

则称 \(p\) 是 \(f\) 的 \(k\) 重因式。

- \(k=1\)：单因式。
- \(k\geq2\)：重因式。

**② 最核心定理：求导使重数减1**

\[ \boxed{p^k\parallel f\iff p^{k-1}\parallel f'} \]

其中 \(p^k\parallel f\) 表示 \(p\) 恰好是 \(k\) 重因式。

**直觉：** 求导会使每个不可约因式的重数减少1。

**③ 判断是否有重因式（最重要的做题工具）**

\[ \boxed{f\text{有重因式}\iff (f,f')\neq1} \]

\[ \boxed{f\text{无重因式}\iff (f,f')=1} \]

直觉：重因式求导后还剩至少一重，因此 \(f\) 与 \(f'\) 存在公因式。

**④ 去掉重因式，保留全部不同的不可约因式**

\[ \boxed{g=\frac{f}{(f,f')}} \]

例如：

\[ f=p^3q^2r \]

则

\[ (f,f')=p^2q \]

因此

\[ g=pqr \]

**直觉：** 最大公因式收集了所有多余的重数，除掉即可。

**⑤ 数域扩张不改变重因式的存在性**

设 \(K\subseteq F\)，则

\[ \boxed{f\text{在}K[x]\text{中有重因式} \iff f\text{在}F[x]\text{中有重因式}} \]

**直觉：** 扩大数域可能使不可约因式进一步分解，但不会凭空产生重复因式。

------

### 二、两个重要的做题技巧

**1. 平移不改变重因式**

\[ \boxed{f(x)\text{有重因式}\iff f(x+b)\text{有重因式}} \]

常用于消去三次多项式的二次项。

**2. 判断三次多项式是否有重因式**

对于

\[ f(x)=x^3+ax+b \]

有

\[ \boxed{f\text{有重因式}\iff 4a^3+27b^2=0} \]

不必死记一般三次多项式的复杂判别式，掌握利用 \(f'\) 和辗转相除法推导即可。

------

### 三、最终做题思维

| 题目要求           | 第一反应             |
| ------------------ | -------------------- |
| 判断有无重因式     | 求 \((f,f')\)        |
| 求没有重因式的部分 | \(f/(f,f')\)         |
| 判断某因式的重数   | 利用求导使重数减1    |
| 数域扩张后的重因式 | 重因式存在性不变     |
| 一般三次多项式     | 求导或平移消去二次项 |

**整节最值得记住的一句话：**

> 求导使不可约因式的重数减1，因此研究重因式，本质上就是研究 \(f\) 与 \(f'\) 的最大公因式。

这也是7.5节所有核心定理和大多数习题的出发点。
