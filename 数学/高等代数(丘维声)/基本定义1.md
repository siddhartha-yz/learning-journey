### 一、基本代数结构

| 结构            | 定义                                               | 核心特点                           |
| --------------- | -------------------------------------------------- | ---------------------------------- |
| **群（Group）** | 集合＋一种运算，满足结合律、单位元、逆元存在       | 可逆                               |
| **阿贝尔群**    | 群＋交换律                                         | 可逆、可交换                       |
| **环（Ring）**  | 加法构成阿贝尔群，乘法满足结合律，两者满足分配律   | 两种运算                           |
| **交换环**      | 环＋乘法交换律                                     | \(ab=ba\)                          |
| **整环**        | 含幺交换环＋无零因子，且 \(1\ne0\)                 | \(ab=0\Rightarrow a=0\) 或 \(b=0\) |
| **域（Field）** | 含幺交换环＋每个非零元素都有乘法逆元，且 \(1\ne0\) | 非零元素可除                       |

注：环是否默认含幺元，不同教材约定可能不同。

**包含关系：**

\[ \boxed{\text{域}\Rightarrow\text{整环}\Rightarrow\text{交换环}\Rightarrow\text{环}} \]

环的加法结构必然是阿贝尔群。

### 二、基本映射关系

设 \(f:A\to B\)。

| 映射     | 定义                         | 直觉     |
| -------- | ---------------------------- | -------- |
| **单射** | \(f(a)=f(b)\Rightarrow a=b\) | 不合并   |
| **满射** | \(f(A)=B\)                   | 不遗漏   |
| **双射** | 单射＋满射                   | 一一对应 |
| **同态** | 保持指定的代数运算           | 结构保持 |
| **同构** | 双射＋同态                   | 结构等价 |

**同态的具体条件：**

群同态：

\[ f(ab)=f(a)f(b) \]

环同态：

\[ \begin{cases} f(a+b)=f(a)+f(b)\\ f(ab)=f(a)f(b) \end{cases} \]

对于含幺环同态，通常还要求 \(f(1)=1\)。

**核心关系：**

\[ \boxed{\text{同构}=\text{双射}+\text{保持代数结构}} \]

### 三、结合高等代数理解

设 \(K\) 为数域。

\[ \boxed{K\subseteq K[x]\cong K_{\mathrm{pol}}} \]

其中：

- \(K\)：域。
- \(K[x]\)：整环，但不是域。
- \(K_{\mathrm{pol}}\)：多项式函数环。

这里 \(K\subseteq K[x]\) 表示把常数视为常数多项式；当 \(K\) 为无限域时，\(K[x]\cong K_{\mathrm{pol}}\) 表示二者**作为环同构**。

### 四、最重要的数学直觉

**代数结构研究的是运算规律，映射研究的是结构之间的关系。**

\[ \boxed{ \begin{aligned} \text{群、环、域}&\longrightarrow\text{对象内部有什么结构}\\ \text{同态、同构}&\longrightarrow\text{对象之间如何保持结构} \end{aligned} } \]

**牢记：同构不要求两个集合相等，只要求它们的代数结构等价。**
