## 数列极限｜高频二级结论（精简版）

只保留**非显然、复用率高、适合直接记忆**的结论。

**1. 增长速度比较**

\[ \boxed{(\ln n)^p\ll n^q\ll a^n\ll n!\ll n^n} \]

其中 \(p,q>0,\ a>1\)，且 \(f\ll g\) 表示 \(f/g\to0\)。

**2. \(n\) 次方根型**

\[ \boxed{\lim_{n\to\infty}n^{1/n}=1} \]

\[ \boxed{\lim_{n\to\infty}\frac{n(n^{1/n}-1)}{\ln n}=1} \]

**3. \(1^\infty\) 型**

\[ \boxed{ x_n\to0,\quad x_ny_n\to A \implies (1+x_n)^{y_n}\to e^A } \]

**4. 比值与根值**

若 \(a_n>0\)，且

\[ \frac{a_{n+1}}{a_n}\to q\geq0, \]

则

\[ \boxed{\sqrt[n]{a_n}\to q} \]

并且：

\[ \boxed{ \begin{cases} q<1\implies a_n\to0,\\ q>1\implies a_n\to+\infty. \end{cases} } \]

\(q=1\) 时无法判断。

**5. Cesàro 定理**

\[ \boxed{ a_n\to a \implies \frac1n\sum_{k=1}^n a_k\to a } \]

推论：

\[ \boxed{ a_{n+1}-a_n\to a \implies \frac{a_n}{n}\to a } \]

**6. Stolz 定理（进阶）**

若 \(b_n\) 严格递增且 \(b_n\to+\infty\)，则

\[ \boxed{ \frac{a_{n+1}-a_n}{b_{n+1}-b_n}\to A \implies \frac{a_n}{b_n}\to A } \]

其中 \(A\) 可以是有限实数或 \(\pm\infty\)。

**7. 递推数列的压缩估计**

若存在 \(0<q<1\)，使得从某项开始

\[ |a_{n+1}-A|\leq q|a_n-A|, \]

则

\[ \boxed{a_n\to A} \]

------

这七条中，**1、3、4、5 优先记忆**；第 6 条是非常实用的进阶工具。以后整理二级结论就按这个密度，排除定义级、显然推论和低频公式。
