# Simate-beta：压缩视觉历史的机器人动作策略

背景：RoboDojo 榜单署名为 Simate，公开推理适配由 SIPAILab 提供。当前未提供论文及 arXiv 链接，以下依据实现说明整理，不视为完整论文解读。[公开说明](https://github.com/XPolicyLab/XPolicyLab/blob/main/policy/Simate_beta/README.md)

一、定位与问题
Simate-beta 在已核实的榜单快照中归类为 VLA。它涉及的主要问题是：单帧观测难以反映任务进度，而直接输入大量历史图像会增加计算成本。例如，当前画面可能无法区分某个操作是否已经执行，需要结合过去的观测。这是具身策略的常见问题，不能据此认定它提出了全新研究方向。

二、公开机制
实现对当前画面和历史画面采用不同处理方式。当前三个相机视角保留完整视觉 token 网格；历史使用主相机画面，默认每隔20个动作步采样一次，共保留25帧。每张历史图像经过 SigLIP 和自编码器编码器，将16×16的 token 网格压缩为4×4，即每帧 token 数量降至原来的1/16。该比例不代表整个系统加速16倍。

历史按时间顺序输入，回合开始时缺失的帧被屏蔽，不同环境的历史独立保存，并在回合结束后清空。动作采用相对关节预测，结合当前关节状态解码；夹爪预测绝对开合程度。[机制与配置来源](https://github.com/XPolicyLab/XPolicyLab/blob/main/policy/Simate_beta/README.md#evaluation)

三、设计取舍
可以把该设计理解为“当前看细，过去压缩着看”：当前观测服务于即时控制，压缩历史补充任务阶段信息。潜在代价是历史中的小物体、精细位置或接触细节可能丢失；固定间隔采样也可能漏掉短暂事件。这些属于机制分析，实际影响需要实验验证。

四、成绩与创新边界
10月9日榜单快照中，其平均 Score 为33.95、成功率27.96%；长程任务成功率为43.42%，在该表所列方法中较突出。但这些结果不能单独证明历史压缩模块的贡献。[榜单快照表3](https://arxiv.org/html/2610.18867v2#S4.T3)

历史记忆和视觉压缩并非全新思路。若要证明独立创新，需要与已有方法在相同数据、底模和计算预算下比较，并提供去除历史、改变压缩方式等消融实验。当前公开材料不足以判断它突破了什么既有瓶颈。

五、开放程度
已提供推理代码及可下载权重，但未提供完整训练代码、配置和数据。因此可尝试复现评测，尚不能从头复现训练；使用权限仍需遵守许可证。

核心总结：Simate-beta 提供了“保留当前细节、压缩历史信息”的具体实现；性能来源、独立创新与泛化收益仍需更充分公开证据。
