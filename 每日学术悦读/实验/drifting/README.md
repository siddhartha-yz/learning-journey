```bash
python3 '每日学术悦读/实验/drifting/check_symmetric_equilibrium.py'
```

脚本在同目录生成 `symmetric-equilibrium-results.json`，并打印结果。

## 检查什么

真实分布在 -2 和 2 各放一半概率质量；生成分布在 -s 和 s 各放一半。使用距离的指数核计算加权中心之差，考察生成位置上的原始漂移平方与分布的平方 Wasserstein 距离。

在 s = 0 时，生成样本处的漂移为 0，但分布距离为 4。s = 0.001 时，漂移平方约为 0.000004，分布距离仍约为 3.996。输出还包含外部探针 x = 1 处的漂移，帮助区分“生成位置上的零漂移”和“全空间零漂移”。

## 边界

这是离散对称分布的原始场诊断，没有训练生成器，没有 minibatch、漂移归一化或 SGD。原子分布不满足 full-support 假设，因此它不能反驳附录中依赖该假设的结论，也不能证明论文实际系统必然塌缩。

它检查的只是：生成样本位置上的小漂移，是否可以无条件当作分布正确的证据。
