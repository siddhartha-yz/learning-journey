MeanFlow 最值得抓住的一句话是：

**普通 Flow Matching 学“现在往哪走”，MeanFlow 学“从现在到目标时刻，整段路的平均速度是多少”。学准后，就能直接跨过去。**

我读的是 **《Mean Flows for One-step Generative Modeling》**，作者为 Zhengyang Geng、Mingyang Deng、Xingjian Bai、J. Zico Kolter 和 Kaiming He，以下以 2025 年 5 月的原始论文及附录为主。它是一篇**有数学推导、主要靠实验验证效果的方法论文**。[论文全文](https://arxiv.org/pdf/2505.13447)

下面先讲人话，再讲公式；原文结论、我的分析和研究猜想会分开标明。

**1. 研究问题与重要性。**

生成图片，可以理解成把一团随机噪声逐渐变成有结构的图片。

Flow Matching 通常训练一个网络：给它当前状态和时间，让它预测下一瞬间的移动方向与速度。生成时反复调用网络，沿着这些方向走，最后到达图片分布。

问题是：**知道当前位置的速度，通常不足以知道很远以后的终点。** 如果轨迹会拐弯，一开始就沿当前方向迈一个巨大步子，很容易走偏。因此，多步生成质量不错，一步生成却可能很差。

MeanFlow 要解决的是：能否从头训练一个模型，让它直接预测跨越整段时间所需的位移，同时保留 Flow Matching 的训练信号？做到这一点，可以减少生成时串行调用大模型的次数。

**2. 前人工作与不足。**

一步生成在 MeanFlow 之前已经存在，学习跨时间映射也已有研究。它的贡献需要放在这些工作中理解。

| 路线                    | 已经能做到什么                                   | MeanFlow 要处理的问题                                      |
| ----------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| Flow Matching           | 学习瞬时速度，数值积分生成                       | 大步积分容易产生误差                                       |
| Rectified Flow / reflow | 通过重新构造训练配对等方式拉直轨迹               | 初始配对的直线插值，并不保证实际生成轨迹也直               |
| Consistency Models      | 把同一生成轨迹上的状态映射到共同终点             | 从头训练时，稳定性与训练安排比较讲究                       |
| Flow Map Matching       | 直接学习两个时刻之间的映射                       | 已提供相关数学框架，因此“两时间映射”本身并非 MeanFlow 首创 |
| Shortcut Models         | 学习不同时间跨度的跳跃，并约束大小步之间的一致性 | 需要处理跨跨度的自洽关系                                   |

MeanFlow 的具体切入点是：**把平均速度定义成一个真实存在的场，再由定义推导训练关系。**

这里不能照单全收地把此前方法都说成“缺乏理论”。例如，Flow Map Matching 已经研究了两时间映射的方程、训练目标及误差控制。MeanFlow 的价值在于平均速度这一参数化、相应训练方式，以及一步图像生成上的实证效果。[MeanFlow §2–4](https://arxiv.org/pdf/2505.13447)、[Flow Map Matching](https://arxiv.org/abs/2406.07507)

**3. 重建作者的思考路径。**

以下是根据已有背景重建的思路，不是作者的研究日记。

首先，多步 Flow Matching 表明：从噪声到数据的运输过程是可以学的，困难之一在于生成时需要把整条路积分出来。

接着，如果目标是一步生成，就应该追问：网络预测的量，是否与“一步跨过去”匹配？瞬时速度描述局部运动，而一步生成需要整段位移。

整段位移当然可以通过积分得到，但如果训练每个样本都要完整求解轨迹，成本又会很高，还可能需要预训练的速度模型。

于是，一个自然的问题出现了：**能不能找到“整段位移”与“当前位置速度”之间的局部关系，用局部可得的信号来训练全局跳跃？**

这就通向了 MeanFlow 的核心推导。

**4. 核心 Intuition。**

沿着弯路开车时，当前车头朝向不等于终点所在方向。Flow Matching 预测类似于当前车速的量，MeanFlow 预测整段位移除以时间得到的平均速度。它通过一个微积分恒等式学习这个量，因此生成时可以直接预测整段跳跃。



这张图是我画的概念示意。“直达终点”的前提是平均速度预测准确；它并没有把原来的弯曲轨迹变成直线。

**5. 具体方法与完整 Pipeline。**

以 ImageNet 上生成一张猫的图片为例。下面说明的是论文流程，不是我重新训练了 ImageNet 模型。

训练时：

1. **取真实图片及类别。** ImageNet 实验先用预训练 VAE 把图片编码成 latent。\(256\times256\) 图片对应 \(32\times32\times4\) 的 latent。
2. **采样随机噪声与两个时间。** 真实 latent 记为 \(x\)，噪声记为 \(\epsilon\)，两个时间满足 \(0\le r\le t\le1\)。
3. **构造当前状态。** 使用\[ z_t=(1-t)x+t\epsilon. \]\(t=0\) 是数据，\(t=1\) 是纯噪声。
4. **网络预测平均速度。** 输入当前状态 \(z_t\)、当前时间 \(t\)、目标时间 \(r\) 和类别，输出 \(u_\theta(z_t,r,t)\)。
5. **计算训练目标。** 利用已知的样本速度 \(\epsilon-x\)，结合网络的方向导数，构造平均速度的训练目标。
6. **更新网络。** 训练目标使用 stop-gradient。部分样本设置 \(r=t\)，让同一个网络也学习瞬时速度。

生成时：

\[ \epsilon\sim\mathcal N(0,I) \quad\longrightarrow\quad \hat x=\epsilon-u_\theta(\epsilon,0,1\mid\text{猫}) \quad\longrightarrow\quad \text{VAE 解码成图片}. \]

**训练时能看到真实图片；生成时只需要噪声和类别。**

论文还把 classifier-free guidance 纳入训练所学习的场，因此生成时可以保留一次生成网络调用。原版的 guidance 设置在训练时确定，灵活性受到限制。[原文 §4、附录 A–B](https://arxiv.org/pdf/2505.13447)

这里两个口径要记住：

- “从头训练”指 MeanFlow 生成模型；ImageNet 实验仍使用预训练 VAE。
- “1-NFE”指生成网络调用一次；VAE 解码仍有计算成本。

**6. 核心数学推导。**

理解这一节，主要需要导数、积分、乘积求导和链式法则。最关键的是区分下面三个量：

| 符号           | 含义                                   |
| -------------- | -------------------------------------- |
| \(\epsilon-x\) | 一对图片与噪声之间的样本条件速度       |
| \(v(z,t)\)     | 把所有可能配对平均后，得到的瞬时速度场 |
| \(u(z,r,t)\)   | 沿生成轨迹从 \(r\) 到 \(t\) 的平均速度 |

**先理解：为什么配对插值是直线，生成轨迹仍可能弯曲？**

训练时，对一组固定的 \(x,\epsilon\)：

\[ z_t=(1-t)x+t\epsilon, \qquad \frac{dz_t}{dt}=\epsilon-x. \]

这条插值线确实是直的。

但网络只看到 \(z_t,t\)，不知道它来自哪一组 \(x,\epsilon\)。很多配对可能产生相同的当前状态，却给出不同的移动方向。平方误差回归学到的是条件平均：

\[ v(z,t)= \mathbb E[\epsilon-x\mid z_t=z]. \]

生成时沿着这个平均速度场运动：

\[ \frac{dz_t}{dt}=v(z_t,t). \]

**平均后的速度会随位置和时间变化，因此实际生成轨迹仍可能拐弯。** 这也是为什么不能直接把 \(\epsilon-x\) 当成整段生成轨迹的平均速度。

**接着，定义真正想学习的量。**

沿同一条生成 ODE 轨迹，从时刻 \(r\) 到 \(t\)，位移为：

\[ z_t-z_r=\int_r^t v(z_\tau,\tau)\,d\tau. \]

平均速度就是位移除以时间：

\[ \boxed{ u(z_t,r,t) = \frac{1}{t-r} \int_r^t v(z_\tau,\tau)\,d\tau } \]

所以：

\[ \boxed{ z_r=z_t-(t-r)u(z_t,r,t). } \]

如果知道准确的 \(u\)，就可以直接算出目标时刻的状态，不需要生成时再做多步积分。

**困难是：积分结果怎么拿来训练？**

MeanFlow 把定义改写成：

\[ (t-r)u(z_t,r,t) = \int_r^t v(z_\tau,\tau)\,d\tau. \]

固定 \(r\)，沿轨迹对 \(t\) 求导。左边用乘积法则，右边用微积分基本定理：

\[ u+(t-r)\frac{du}{dt}=v. \]

整理得到论文的核心公式：

\[ \boxed{ u=v-(t-r)\frac{du}{dt}. } \]

这就是 **MeanFlow Identity**。

它把包含整段积分的定义，改写成了一个局部微分关系。[原文 Eq. 3–6](https://arxiv.org/pdf/2505.13447)

**然后，计算这里的导数。**

\(u\) 的输入是 \((z_t,r,t)\)。随着时间变化，当前位置 \(z_t\) 也在移动，因此这里必须用总导数：

\[ \frac{du}{dt} = \frac{\partial u}{\partial z}\frac{dz_t}{dt} + \frac{\partial u}{\partial r}\frac{dr}{dt} + \frac{\partial u}{\partial t}. \]

因为 \(r\) 固定，且 \(\frac{dz_t}{dt}=v\)，所以：

\[ \boxed{ \frac{du}{dt} = \frac{\partial u}{\partial z}v + \frac{\partial u}{\partial t}. } \]

这可以通过 Jacobian-vector product，即 JVP，计算：

\[ \operatorname{JVP} \left[ u;\,(v,0,1) \right]. \]

其中 \((v,0,1)\) 表示：位置沿速度 \(v\) 移动，\(r\) 不变，\(t\) 正常增加。**不需要显式构造完整 Jacobian 矩阵。**

**最后，把它变成训练算法。**

真实的平均速度场未知，因此用网络导数近似；真实 marginal velocity 也不直接可得，因此原版使用样本速度：

\[ v_{\mathrm{cond}}=\epsilon-x. \]

构造：

\[ u_{\mathrm{tgt}} = v_{\mathrm{cond}} - (t-r) \left( \frac{\partial u_\theta}{\partial z}v_{\mathrm{cond}} + \frac{\partial u_\theta}{\partial t} \right), \]

再优化基础目标：

\[ \boxed{ \mathcal L(\theta) = \mathbb E \left[ \left\| u_\theta(z_t,r,t) - \operatorname{sg}(u_{\mathrm{tgt}}) \right\|^2 \right]. } \]

`sg` 表示：更新参数时，把目标视为常量，避免继续通过其中的 JVP 计算高阶参数梯度。

对应的核心伪代码是：

```
z = (1 - t) * x + t * noise
v = noise - x

u, dudt = jvp(model, (z, r, t), (v, 0, 1))
target = v - (t - r) * dudt
loss = squared_error(u, stopgrad(target))
```

论文实际还使用自适应 loss weighting 等设计。[原文 Eq. 9–11、Algorithm 1](https://arxiv.org/pdf/2505.13447)

有两个容易误解的地方：

第一，当 \(r=t\) 时，修正项消失，目标退化为普通 Flow Matching。这让瞬时速度学习与平均速度学习可以放在同一网络中。

第二，**恒等式严格成立，不等于这个训练算法被证明一定收敛。** 原文附录证明的是：满足恒等式并具备相应正则性、边界行为时，可以恢复平均速度定义；它没有证明有限网络经 SGD 一定达到这个解。

**7. 实验设计与结论。**

论文的实验可以围绕四个问题理解：

| 假设或问题                           | 怎么验证                   | 结果说明什么                                                 |
| ------------------------------------ | -------------------------- | ------------------------------------------------------------ |
| 学跨时间平均速度，能改善一步生成吗？ | 改变 \(r\ne t\) 的训练比例 | 同一消融设置下，纯 FM 的一步 FID 为 328.91；25% 跨时间样本时为 61.06 |
| 核心导数关系真的重要吗？             | 故意使用错误的 JVP 方向    | 错误方向明显破坏效果，支持链式法则中的各项有实际作用         |
| 方法能否随模型和训练规模提升？       | 增大模型并延长训练         | 一步生成质量随规模改善                                       |
| 能否在一次调用中获得 guidance 收益？ | 比较不同 guidance 设置     | 可以明显改善质量，同时保留 1-NFE                             |

主结果是在 ImageNet \(256\times256\) 上，对 50,000 张生成图片计算 FID，越低越好：

| 模型                               | NFE  | FID      |
| ---------------------------------- | ---- | -------- |
| iCT-XL/2                           | 1    | 34.24    |
| Shortcut-XL/2                      | 1    | 10.60    |
| MeanFlow-XL/2                      | 1    | **3.43** |
| MeanFlow-XL/2                      | 2    | 2.93     |
| MeanFlow-XL/2+，更长训练与不同配置 | 2    | **2.20** |

这些结果支持：**在论文比较的从头训练 diffusion/flow 方法中，MeanFlow 显著提升了一步生成质量。** 不能把 2.20 当作默认训练模型的一步结果。

结论也有明确边界：CIFAR-10 上 MeanFlow 的一步 FID 是 2.92，具有竞争力，但并未超过表中 iCT 的 2.83；ImageNet 表中也有 FID 更低的 GAN 和多步模型。因此，这不是“所有生成模型中最好”的结论。[原文 Table 1–3](https://arxiv.org/pdf/2505.13447)

**8. Take-aways。**

**用五句话概括：** Flow Matching 学习瞬时速度，通常需要积分生成。训练配对采用直线插值，也不能保证实际生成轨迹笔直。MeanFlow 学习跨时间区间的平均速度，使输出直接对应整段位移。它通过平均速度与瞬时速度之间的微分恒等式构造训练目标，无需先提供完整轨迹积分。实验展示了强的一步生成效果，但训练稳定性与有限模型的近似误差仍是关键问题。

**用三句话概括：** 想一步生成，就让模型预测整段跳跃需要的量。MeanFlow 用微积分关系，把平均速度变成可训练的对象。它减少了生成时的积分步骤，但平均速度能否学准仍取决于训练。

**用一句话概括：** **MeanFlow 把“生成时逐步积分”转化为“训练时学习整段平均速度”。**

**9. 最脆弱的假设。**

我的判断是，最关键的实践假设是：

> **用带随机性的条件速度，加上网络自身产生的导数目标，能够稳定地把准确的平均速度学出来，尤其是在长时间跨度上。**

这比“平均速度存在”强得多。

原版目标包含网络自身的导数。网络更新后，目标也会变；同时，随机条件速度进入 JVP，可能被网络的空间导数放大。因此，目标均值在理想条件下符合正确关系，并不能保证实际优化容易。

这条脆弱性有后续证据。作者的 **improved MeanFlow，iMF** 专门讨论了原版训练目标的网络依赖，以及条件速度作为 JVP 方向时引入的高方差，并改用预测的 marginal velocity 作为方向。[iMF §4.1](https://arxiv.org/abs/2512.02012)

后续 **On Variance Reduction in Learning Mean Flows** 又从随机梯度方差角度分析了这个问题。[后续分析](https://arxiv.org/abs/2605.09235)

所以，更准确的理解是：**MeanFlow 给出了正确目标应满足的关系，并展示了有效训练方案；从这个关系到稳定优化，中间仍有需要研究的距离。**

上述条件期望解释也不能直接照搬到所有自适应加权设置，因为权重本身可能依赖随机训练误差。

**10. 一周能做的最小复现实验。**

我建议先验证核心机制，用二维数据即可。

数据选 **8 个高斯簇**和 **two moons**。网络使用相同大小、带时间输入的小 MLP，对比：

- 普通 Flow Matching，1 步采样；
- 普通 Flow Matching，足够多步采样，作为参考；
- 原版 MeanFlow，1 步采样。

保持模型容量一致，同时记录训练时间和随机种子。检查三类结果：生成分布与真实分布的距离，例如 sliced Wasserstein distance；模式是否覆盖完整、各簇比例是否正确；训练 loss 与梯度波动。

一周可以按这个顺序推进：先把 FM 多步基线跑正确，再实现 JVP 与 MeanFlow，最后比较不同 \(r\ne t\) 比例并重复多个种子。

**支持核心机制的结果**是：MeanFlow 一步显著优于 FM 一步，并接近 FM 多步，且各模式覆盖正常。

**挑战训练方案的结果**是：模型容量足够、实现核验正确时，MeanFlow 在多次运行中仍持续不稳定，或者出现 loss 看似改善、模式覆盖却变差。

这个实验验证的是机制和训练行为，不是复现论文的 ImageNet FID。

**11. 最强反例设计。**

我会攻击“正确恒等式能否变成低噪声、好优化的监督”，而不会攻击恒等式本身。

可以先用一个完全可解析的例子：

\[ x\sim\mathcal N(0,\sigma^2), \qquad \epsilon\sim\mathcal N(0,1), \]

两者独立，仍采用：

\[ z_t=(1-t)x+t\epsilon. \]

对应 marginal ODE 的准确端点映射非常简单：

\[ z_0=\sigma z_1. \]

因此，在 \(r=0,t=1\)：

\[ u^*(z_1,0,1)=(1-\sigma)z_1. \]

**正确答案只是一个线性函数，表达能力完全不难。**

但把这个准确的平均速度及其导数，代入原版条件训练目标，可以推得：

\[ u_{\mathrm{tgt}} = u^*-\sigma x. \]

固定当前噪声状态后，目标方差为：

\[ \boxed{ \operatorname{Var}(u_{\mathrm{tgt}}\mid z_1)=\sigma^4. } \]

相比之下，普通条件速度目标的方差是 \(\sigma^2\)。

我用每组 50 万个样本做了数值核验：

| 数据标准差 \(\sigma\) | FM 目标方差 | MeanFlow 目标方差  |
| --------------------- | ----------- | ------------------ |
| 1                     | 约 1        | 约 1               |
| 2                     | 约 4        | 约 16              |
| 5                     | 约 25       | 约 624，理论值 625 |

这说明：**即使平均速度已经完全正确，随机训练目标仍可能剧烈波动，原始平方 loss 也不会因此变成零。**

这个例子没有证明 MeanFlow 无法训练成功；统一缩放也可通过归一化缓解。它真正挑战的是“目标正确，所以优化自然容易”的推断。更强的后续测试，应使用局部伸缩差异很大的多模态分布，检查这种噪声是否对应可预测的训练失败。

这是我推导并做的数值核验，不是原论文实验；一般性的方差放大机制已有后续研究。[核验脚本](/home/yang-zhi/文档/ChatGPT/读论文/sources/meanflow/check_and_illustrate.py)、[核验结果](/home/yang-zhi/文档/ChatGPT/读论文/sources/meanflow/gaussian_noise_check.json)

**12. Follow-up Research Idea。**

先校准研究价值：例如 NeurIPS 2024 对 VAR 的获奖介绍，强调了生成组织方式的改变，以及实验与 scaling 证据。我的理解是，值得追求的方向应当改变我们对问题的认识，并给出可检验的新结论；“加一个模块让 FID 降一点”本身不足以说明贡献。[官方获奖说明](https://media.neurips.cc/Conferences/NeurIPS2024/NeurIPS2024_Best_Paper_Awards.pdf)

对 MeanFlow，直接提“减少 JVP 噪声”已经撞上 iMF 和方差分析工作。把“一步计算可能藏进网络深度”作为新发现也不合适，已有 **Depth as Time in One-Step Generative Models** 研究这一现象。[相关工作](https://arxiv.org/abs/2610.03626)

我更愿意提出下面这个**尚待验证、未确认 novelty 的研究问题**：

> **一步生成的困难，究竟来自目标分布本身，还是来自我们要求模型模仿的那条运输过程？**

它与 §9 的关系是：当平均速度学不好时，我们往往归因于优化不稳定。但还可能存在另一层问题：选定 ODE 的端点映射很复杂，而生成同一个目标分布，可能存在容易得多的映射。

可以借鉴神经网络逼近理论和最优运输的观点，把两件事分开测量：

- 在固定模型与计算预算下，逼近某个指定 flow map 有多难？
- 在同样预算下，只要求生成正确分布，有多难？

**第一个实验**可以从低维可控分布开始，构造通向相同目标分布、但复杂度不同的运输映射。用准确端点配对进行监督训练，先排除自举目标和 JVP 噪声；再与 MeanFlow 训练比较，分别测端点配对误差和最终分布误差。

如果指定映射始终难学，但同预算的另一生成映射能准确覆盖目标分布，就支持“困难部分来自运输选择”的解释。如果给出准确端点监督后问题就消失，则更支持优化噪声是主要瓶颈。

潜在贡献应落在**区分并刻画分布生成难度与指定运输的学习难度**，再由此导出运输选择原则。仅观察到不同轨迹效果不同，还不足以构成新贡献；当前近邻核对也不足以把这个方向认定为 novel。
