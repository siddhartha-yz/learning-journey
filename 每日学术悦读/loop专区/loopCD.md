Decoding Looped Transformers Better for (Almost) Free（LoopCD）

__团队：Apple MLR；一作 Weihao Liu 是 UIC 博士生，工作在苹果实习期间完成，指导者为 Ruixiang Zhang。
状态：2026年10月 arXiv 预印本，未查到会议接收确认；__

Looped Transformer 是共享参数的循环架构：每个 token 输出前，反复运行同一模块。LoopCD 中 CD 指 Contrastive Decoding（对比解码），它不改权重、不再训练，只改变已有状态的读出和候选选择。CoT 则把推理写成跨 token 的文字；内部循环、CoT 和 LoopCD 可以共同使用。

动机是末轮预测丢弃了早轮信息。关键假设：相对早期更被后续计算支持的候选，可能更可靠。因此，除了末轮概率，还利用早晚预测的差异；这不保证越算越对，也不意味着参考越弱越好。

Logits 版的核心公式是：
z′＝z末＋ω（z末－z早）。
其中 z 是词表打分，ω 控制外推强度。它奖励后续计算中上升更多的候选，可以改变候选排序；降低正温度只统一缩放单步 logits，不能改变该步排序。LoopCD 也不是真多循环：它沿已有差分外推，没有重新执行下一轮的非线性计算。

两版实现的区别在对比位置。Logits 分别读出早、晚状态，多一次循环后的 coda 层与输出头计算；尾部网络越深，额外成本越大。Hidden 先沿早晚差分外推隐藏状态，再通过 coda 和输出头，只读出一次，但仍需保存参考状态并做向量运算。由于后续归一化等操作非线性，两版并不等价。标准深度通常取首轮为参考；Huginn 的 Hidden 因初始化噪声，主实验改用第六或第七轮。

自适应 ω 根据末轮前两名的概率差调整：差距小则干预更强，差距大则减弱。它是启发式，不知道答案是否正确，最大强度仍需调节。Logits 已有末轮概率；Hidden 若照做，就需额外读出原末轮，失去单次读出的优势，所以论文只给 Hidden 使用固定强度。生成中的干预过强会让错误随前缀累积。

真正新增的不是“强减弱”本身：传统 CD 对比大小模型，DoLa 对比早晚层；LoopCD 利用共享模块完整轮次间天然对齐的强弱预测，并提供低成本的隐藏状态实现，思路接近扩散模型的 autoguidance。实验证明若干设置有效，部分任务下降，不能推成每任务改善。减半循环保住表现的结果限于所测七项选择题均值；节省幅度按理论前向 FLOPs 核算，不能等同实际延迟同比下降。
