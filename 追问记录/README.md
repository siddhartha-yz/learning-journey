## 怎样追加记录

1. **先找原文，再筛选。** 记忆用于定位，可访问的原始会话用于核对。没有取回原文的聊天暂不编写。
2. **选能形成问题链的内容。** 保留具体质疑、概念联系、反例、纠错和证据要求；省略泛泛求解释、简单失误、临时求助及无关私人内容。
3. **补上下文，不编好问题。** 指代不明时用整理者说明交代背景；不润色用户原话，也不把 AI 后来提出的问题冒充用户提问。
4. **有正文就关联，无正文可独立。** 使用 [模板](./TEMPLATE.md)，按主题放置并更新此索引。跨会话选段注明时间，避免制造连续对话的假象。
5. **区分回答与验证。** AI 摘要、原答、整理补注明确标识；保留会影响结论的限制和纠正。保存回答不等于独立完成推导、验证论文或证明已经掌握。
6. **只发布精选片段。** 来源使用标题、消息标识或日志行号定位，不附包含未选私人内容的完整聊天入口。系统提示、工具日志和本机信息不入库。
