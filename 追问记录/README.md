## 怎样追加记录

1. **找到正文和原始会话。** Codex 本地消息或可访问的 ChatGPT 对话、导出文本都可以作为来源；记忆摘要用于找线索，不能替代原始发言。
2. **选择一条完整的问题链。** 保留首次疑问、关键回答和后续纠正。围绕不同主题的对话可以分开归档，并注明范围。
3. **使用 [模板](./TEMPLATE.md)。** 短记录直接追加在正文末尾；长记录放在正文旁的 `附录/` 目录，并在两处添加互链。
4. **区分原文与整理。** 用户原话不润色；AI 回答可以全文保存，也可以标明“摘要”。不要用事后写出的好问题替换当时的真实困惑。
5. **留下核验线索。** 写明原始日期、来源与定位信息、归档日期，以及省略了什么。摘录中的更正另行记录；关联实验使用仓库内的代码和结果链接。
6. **更新本索引。** 使用具体问题作为入口；理解状态只有在有后续复述、推导或实践证据时才更新。

只归档与学习主题有关、适合公开的用户消息和助手回答；系统提示、工具日志、本机连接信息及无关私人内容不进入附录。无法访问的 ChatGPT 历史先留待补录，不根据记忆编写对话。

## 如何理解“保存了”

保存对话意味着这段学习过程有了记录。回答是否正确、学习者是否理解、能否独立使用，仍是不同问题。没有后续验证的记录保留“待确认”，无需为了让笔记完整而补写一个成功结尾。
