**第 1 题：名称字符规则检查（15 分，建议 10 分钟）**

输入一串字符，以 `#` 结束，检查它是否符合以下名称字符规则：

- 第一个字符只能是英文字母或下划线 `_`；
- 后续字符只能是英文字母、数字或下划线；
- 名称不能为空。

本题**只检查以上字符规则，不检查 C++ 关键字和保留名称**。

输出两个内容，用空格分隔：

- 符合规则：输出 `valid 0`；
- 不符合规则：输出 `invalid` 和**第一个违反规则的字符位置**，位置从 `1` 开始；
- 名称为空：输出 `invalid 0`。

`#` 不属于名称。保证输入没有空白字符，名称长度为 `0～100`。

样例输入 1：

```
_a2#
```

样例输出 1：

```
valid 0
```

样例输入 2：

```
ab$3#
```

样例输出 2：

```
invalid 3
```

**第 2 题：寻找自整除数（20 分，建议 15 分钟）**

如果一个正整数满足：

1. 十进制各位中没有数字 `0`；
2. 它能够被自己的**每一位数字**整除；

就称它为“自整除数”。

例如 `128` 能被 `1、2、8` 分别整除，因此符合条件。

输入两个整数 `L、R`，在闭区间 `[L, R]` 中寻找自整除数，输出：

```
符合条件的个数 最小的自整除数 最大的自整除数
```

如果一个也没有，输出：

```
0 -1 -1
```

数据范围：

```
1 ≤ L ≤ R ≤ 100000
R - L ≤ 9999
```

样例输入 1：

```
1 22
```

样例输出 1：

```
13 1 22
```

样例输入 2：

```
10 10
```

样例输出 2：

```
0 -1 -1
```

**第 3 题：评选优秀小组（20 分，建议 20 分钟）**

某班有 `n` 个小组，各组人数可能不同。按照**组内成员成绩的平均分**评选优秀小组：

- 平均分最高的小组获胜；
- 如果平均分相同，编号较小的小组获胜。

输入第一行是小组数 `n`。

接下来有 `n` 行，第 `i` 行先输入第 `i` 组人数 `m`，再输入该组 `m` 名成员的整数成绩。

输出获胜小组的**编号和该组总分**，用空格分隔。小组编号从 `1` 开始。

注意：按实际平均分比较，不能先取整或保留两位小数再比较。

数据范围：

```
1 ≤ n ≤ 100
1 ≤ m ≤ 100
0 ≤ 成绩 ≤ 100
```

样例输入：

```
4
2 80 100
3 90 96 96
1 93
2 93 95
```

样例输出：

```
2 282
```

统计有多少种购买方案。三种笔的购买数量相同，就视为同一种方案，与购买顺序无关。

如果存在方案，在一行中依次输出：

方案总数 5元笔数量 3元笔数量 1元笔数量

如果不存在任何方案，仅输出：

0
```

输入为两个整数 `n、m`，范围：

```
1 ≤ n ≤ 200
1 ≤ m ≤ 1000
```

样例输入 1：

```
10 30
```

样例输出 1：

```
4 4 2 4
```

样例输入 2：

```
3 10
```

样例输出 2：

```
0

**第 5 题：牛顿迭代求立方根（25 分，建议 25 分钟）**

输入一个整数 `n`，用牛顿迭代法计算它的实数立方根，并统计迭代次数。

当 `n ≠ 0` 时，使用公式：

\[ x_{k+1}=\frac{2x_k+\dfrac{n}{x_k^2}}{3} \]

初值规定为：

\[ x_0= \begin{cases} 1,&n>0\\ -1,&n<0 \end{cases} \]

每计算出一个新值，就算完成一次迭代。第一次满足

\[ |x_{k+1}-x_k|<10^{-7} \]

时停止，**使用新值 \(x_{k+1}\) 作为结果，触发停止的这一轮也计入次数**。

特殊规定：

- 当 `n = 0` 时，直接输出 `0.000000 0`；
- 当 `n ≠ 0` 时，即使初值恰好就是立方根，也必须先完成一次迭代再判断。

输出立方根近似值和迭代次数，用一个空格分隔。近似值保留六位小数。

数据范围：

```
-1000000 ≤ n ≤ 1000000
```

要求按照给定公式迭代，不直接调用求根或幂函数得到答案。

样例输入 1：

```
27
```

样例输出 1：

```
3.000000 9
```

样例输入 2：

```
-8
```

样例输出 2：

```
-2.000000 7
```
