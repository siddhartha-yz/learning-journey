**第 1 题：阶梯电费（15 分）**

某地每月电费按以下规则分段计算：

- 不超过 100 度的部分，每度 0.5 元；
- 超过 100 度、不超过 200 度的部分，每度 0.8 元；
- 超过 200 度的部分，每度 1.2 元。

输入本月用电量，输出总电费，保留两位小数。

输入为一个实数，用电量在 `[0, 10000]` 范围内。

样例输入：

```
135
```

样例输出：

```
78.00
```

**第 2 题：删除指定数字（20 分）**

输入一个正整数 `n` 和一个数字 `d`，删除 `n` 中所有等于 `d` 的数字，其余数字保持原来的相对顺序。

输出删除后得到的整数，以及删除的数字个数，用一个空格分隔。

删除后若没有剩余数字，结果记为 `0`；若出现前导零，按普通整数输出。

数据范围：`1 ≤ n ≤ 1000000000`，`0 ≤ d ≤ 9`。

本题要求使用整数运算处理，**不使用字符串或数组**。

样例输入 1：

```
1020302 0
```

样例输出 1：

```
1232 3
```

样例输入 2：

```
1111 1
```

样例输出 2：

```
0 4
```

**第 3 题：最长连续字符段（20 分）**

输入一串英文字母，以 `#` 结束。连续出现的相同字母构成一个字符段，大小写视为不同字母。

输出最长字符段对应的字母及其长度，用一个空格分隔。如果多个字符段长度并列最大，输出**最先出现的那一段**。

保证 `#` 前至少有一个字母，字母总数不超过 10000，输入中没有空格。

本题要求逐个读取字符，**不使用字符串或数组**。

样例输入：

```
aaBBBccDDDd#
```

样例输出：

```
B 3
```

三边只是排列顺序不同，视为同一种三角形。

输出两个整数：三角形种数、最大面积，用一个空格分隔。若不存在，输出 `0 0`。

数据范围：`3 ≤ p ≤ 300`。整数边长的直角三角形面积一定是整数。

样例输入 1：

```
120
```

样例输出 1：

```
3 750
```

样例输入 2：

```
11
```

样例输出 2：

```
0 0
```

**第 5 题：计算常数 e 的近似值（20 分）**

常数 \(e\) 可以用下面的级数近似计算：

\[ e=1+\frac{1}{1!}+\frac{1}{2!}+\frac{1}{3!}+\cdots \]

其中：

\[ k!=1\times2\times\cdots\times k \]

输入一个正实数 `eps`，从第一项 `1` 开始依次累加。遇到**第一项小于 `eps` 的项时停止，该项不加入总和**。

输出得到的近似值，保留六位小数。

数据范围：`0.0000000001 ≤ eps ≤ 0.01`。

样例输入：

```
0.01
```

样例输出：

```
2.708333
```
