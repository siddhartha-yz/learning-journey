## 怎样阅读这些记录

正文用于查阅整理后的知识；追问记录精选有推理、联系、质疑和纠错价值的学习过程。有对应笔记的内容可以作附录；没有原笔记的问题链在主题目录独立保存，由统一索引连接。

新增归档会区分**我的提问原文、AI 回答、整理者摘要和后续验证**。AI 生成的讲解与研究建议不自动代表我已独立掌握或提出；记录不以全量保存聊天为目标，也不为缺失的过程补写成功结尾。旧笔记的角色与来源标注还在逐步补齐。

归档方式和可复用模板见 [追问记录说明](./追问记录/README.md#怎样追加记录)。
